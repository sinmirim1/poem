# 대칭 아트 스튜디오: 수학으로 만드는 현대미술

초등학교 5~6학년용 **미술 × 수학 융합 웹앱**입니다.
학생이 도형을 직접 그리고, 선대칭·점대칭 도형을 만든 뒤, 입체파·초현실주의·팝아트 중 하나로 현대미술 작품을 완성합니다.
(개정 교육과정 5학년 2학기 수학 「합동과 대칭」 단원과 연계)

- 서버 없이 브라우저만으로 동작합니다. 인터넷이 없어도 됩니다.
- 작업은 브라우저 Local Storage에 자동 저장되어, 새로고침해도 그대로 돌아옵니다.
- 작품을 PNG로 저장하거나, 설명이 들어간 결과지를 인쇄·PDF로 저장할 수 있습니다.

---

## 1. 바로 쓰기 (교실용)

저장소 맨 위 폴더의 **`대칭아트스튜디오.html`** 을 더블클릭하면 크롬·엣지에서 바로 열립니다.
이 파일 하나에 앱 전체가 들어 있으니 USB나 공유 폴더로 나눠 주어도 됩니다.

> 작업은 **그 컴퓨터의 그 브라우저**에만 저장됩니다. 여러 반이 같은 컴퓨터를 쓰면
> 수업이 끝난 뒤 결과지를 저장하고 교사용 화면의 "작품 초기화"를 눌러 주세요.

## 2. 개발자용 실행 방법

필요한 것: [Node.js](https://nodejs.org) 18 이상 (24 LTS에서 확인)

```bash
cd symmetry-art-studio
npm install
npm run dev               # http://localhost:5173 에서 개발 서버 실행
npm run typecheck         # 타입 검사만
npm run build             # dist/index.html 한 파일로 빌드
npm run build:classroom   # 빌드 후 저장소 맨 위에 대칭아트스튜디오.html 로 복사
```

## 3. 앱 구조와 사용자 흐름

```
첫 화면 ─┬─ 시작하기 ─▶ ① 사조 고르기 ─▶ ② 대칭 도형 만들기 ─▶ ③ 작품 구성하기 ─▶ ④ 작품 설명 쓰기 ─▶ ⑤ 확인·제출
         ├─ 학생용 사용 방법 (창)                (②③은 같은 작품 제작 화면)
         └─ 교사용 간단 안내 ─▶ 교사용 화면 (수업 목표, 진행 예시, 예시 템플릿, 초기화, 전체 화면)
```

- 위쪽 **단계 표시기**로 지금 몇 단계인지 보이고, 눌러서 자유롭게 오갈 수 있습니다.
- 위쪽 **조건 달성 현황**: `사조` · `선대칭 도형 n / 3개` · `점대칭 도형 n / 3개` · `진행 중 / 대칭 조건 완료`
- 작품 제작 화면 배치

| 위치 | 내용 |
|---|---|
| 위 | 되돌리기·다시 하기, 격자, 격자점에 딱 맞추기, 작도 도우미(간격·점 맞추기·수직평행·좌표·각도) |
| 왼쪽 | 도형 그리기 / 대칭 만들기(세로·가로·기울어진 대칭축, 중심점, 선대칭 복사, 점대칭 복사, 대칭 모두 검사하기) / 고르고 바꾸기(복제, 지우기, **전체 그림 지우기**) |
| 가운데 | 도화지(1440×960). 휠·두 손가락으로 확대/축소, 화면 옮기기 |
| 오른쪽 | **도형 속성**(색과 선을 맨 위에: 채우기 색(닫힌 자유선 포함)·선 색·굵기·모양·투명도, 겹치는 순서, 대칭 확인) / **사조 도구**(팔레트·배경·사조별 효과·스티커) |
| 아래 | 단계별 할 일 한 문장, 다음 단계 버튼 (접을 수 있음) |

화면 폭이 1200px보다 좁으면(태블릿) 오른쪽 패널은 "속성·꾸미기" 버튼으로 여닫는 서랍이 됩니다.

### 대칭 도형의 동작 규칙

선대칭/점대칭 복사를 하면 **원래 도형 + 복사본 + 그때의 대칭축(중심)** 이 하나의 "대칭 도형"으로 묶입니다.

- **함께 움직이기(기본)**: 옮기기·돌리기·크기 바꾸기를 하면 한 덩어리로 움직이고, 꼭짓점 끌기·늘이기·뒤집기·나누기처럼
  모양을 바꾸면 짝 도형이 거울처럼 따라 바뀝니다. → 대칭이 항상 유지됩니다.
- **따로 움직이기**: 원본과 복사본을 따로 옮길 수 있습니다. 대칭이 어긋나면 빨간 표시와 구체적인 힌트가 나타나고,
  "원본에 맞춰 다시 맞추기"로 고칠 수 있습니다. 어긋난 도형은 개수에서 빠집니다.
- 색·선 꾸미기는 짝에게 퍼지지 않아서 양쪽을 다른 색으로 칠할 수 있습니다.

### 대칭 자동 확인 (힌트 방식)

| 선대칭 | 점대칭 |
|---|---|
| 대응점이 대칭축의 서로 다른 쪽에 있는가 | 중심에서 두 대응점까지 거리가 같은가 |
| 대칭축에서 두 대응점까지 거리가 같은가 | 중심·대응점이 한 직선 위에 있는가(180° 회전) |
| 대응점을 이은 선분이 대칭축과 수직인가 | 대응점을 이은 선분의 중점이 대칭의 중심인가 |
| 대응점을 이은 선분의 가운데를 대칭축이 지나는가 | |

막는 대신 "대칭축의 왼쪽과 오른쪽 거리를 다시 확인해 보세요." 같은 힌트와 칸 수를 알려 줍니다.

### 기술 선택: React + TypeScript + SVG

Fabric.js·Konva.js 대신 **SVG를 React로 직접 그리는 방식**을 골랐습니다.

- 대칭 관계(원본 점 i ↔ 복사본 점 i), 대칭축·중심, 학습용 보조선을 모두 같은 좌표계의 순수 데이터로 다룰 수 있어
  검사·힌트·되돌리기 로직이 단순하고 테스트하기 쉽습니다.
- 회전·크기 변화는 점 좌표에 바로 반영해 두므로 별도의 변환 행렬을 추적할 필요가 없습니다.
- 편집 화면, 예시 그림, PNG 저장, 인쇄가 **하나의 그리기 컴포넌트**를 공유합니다.
- 외부 그래픽 라이브러리가 없어 한 파일 빌드가 가볍습니다(약 375KB, gzip 124KB).

## 5. 구현 점검 체크리스트

- [x] 선대칭 도형을 만들 수 있다. — 세로·가로·기울어진 대칭축 + "선대칭 복사"
- [x] 점대칭 도형을 만들 수 있다. — "중심점 찍기" + "점대칭 복사"(180° 회전 복사)
- [x] 각각 3개 이상 만든 여부를 확인할 수 있다. — 위쪽 현황(`n / 3개`), 5단계 확인 목록
- [x] 대칭축과 대칭의 중심을 표시할 수 있다. — 파란 점선 / 보라 십자, 보이기·숨기기 스위치
- [x] 현대미술 사조를 선택할 수 있다. — 1단계 카드(특징·색 분위기·팁·예시), 사조 도구 탭에서 변경 가능
- [x] 도형을 이용해 작품을 구성할 수 있다. — 이동·회전·크기·겹침 순서·배경·말풍선·글자·스티커·사조별 효과
- [x] 작품 설명을 작성할 수 있다. — 4단계 문장 완성 7개(특징 낱말 칩, 생각 도우미)
- [x] 작품을 자동 저장할 수 있다. — Local Storage, 새로고침 후 복원
- [x] 작품을 PNG로 저장할 수 있다. — 작품 그림 PNG / 설명 포함 결과지 PNG
- [x] 인쇄용 결과 화면을 제공한다. — A4 결과지(작품·사조·개수·설명), 인쇄 창에서 PDF 저장
- [x] 태블릿과 데스크톱에서 조작하기 쉽다. — 큰 버튼(44px 이상), 터치·펜·두 손가락 확대, 반응형 서랍 패널
- [x] 안내 문구가 초등 고학년 수준의 쉬운 한국어로 작성되어 있다. — "격자점에 딱 맞추기", "화면 옮기기" 등
