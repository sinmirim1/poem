## 쓰는 법

파일을 내려받아 **더블클릭**하면 브라우저에서 열립니다. 학생이 쓴 내용은
그 기기의 브라우저에만 저장되므로, 다 쓴 뒤에는 이미지나 PDF로 저장해 두세요.
